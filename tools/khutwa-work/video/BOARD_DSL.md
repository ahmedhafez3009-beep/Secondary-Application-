# محرك سبورة خُطوة — دليل وكيل الشرايح

ملف السبورة = صفحة HTML واحدة. القالب: `/home/claude/out/board_template.html` (المحرك كامل + مكان المحتوى بين `/*__CONTENT_START__` و`/*__CONTENT_END__*/`). المرجع الحي: `/home/claude/out/khutwa_hist_board_A.html` (A0–A3) — اقرا محتواه كمثال للأسلوب والكثافة.

## العالم والكاميرا
- العالم 3200 عرض؛ شبكة خلايا 1066×600. `cell(c,r)` يحدد أصل الخلية (c=0 أقصى اليمين … 2 أقصى الشمال؛ r من 0 لتحت)، و`go(c,r)` بيحدد الخلية ويحرك الكاميرا ليها. ابدأ من `go(0,0)` وامشِ ثعباني. تقدر تستخدم صفوف r لحد 5 (الخلفية ممتدة لـ y=3600 لازم؛ لو احتجت أكتر كبّر مستطيلات الخلفية).
- جوّه الخلية: x من 10 لـ 1056، وy ≤ 528 (آخر 12% من الشاشة شريط الترجمة). سيب أعلى يمين كل لقطة (~300×70) فاضي لشارة الاسم، وأعلى الشمال (~330×40) لاسم الشريحة.
- `camTo(o,x,y,w,h,dur)` لأي حركة كاميرا حرة (النسبة 16:9).

## السطور
`slide('B1 · عنوان الشريحة')` بداية شريحة (تسجيل الصوت بيتم شريحة شريحة).
`line(id, source, spoken, ()=>{ عناصر })` — جملة منطوقة واحدة؛ المدة = 0.58ث/كلمة + الوقفات `[[1.0]]`. النص المنطوق لازم يطابق السكريبت حرفيًا.

## العناصر (o = offset؛ استخدم دايمًا `at('كلمة')` = لحظة نطق الكلمة، أو `at('كلمة',n)` للتكرار رقم n، `atp()` بداية أول وقفة، `EOL()` آخر السطر)
- `W(o,x,y,text,size,color,anchor)` كتابة بالقلم؛ x = الحافة اليمين (anchor 'middle' للتوسيط). `WC(o,text,color)` يكمل على نفس سطر آخر W.
- `P(o,pathD,color,width,dur,fill,cls)` خط يرسمه القلم (إحداثيات محلية للخلية)؛ fill بيظهر بعد الخط زي الماركر.
- `ST(o,x,y,ok)` ختم ✓/✗ مرسوم. `Q(o,x,y,dur)` «؟» دهبي بينبض. `AR(o,x1,y,x2)` سهم لليسار. `CARD(o,x,y,w,h,color,fill)`. `CDR(o,x,y,r,n)` حلقة عدّ n ثواني للوقفات. `FADE(o,n)` يخفي آخر n عناصر عند o. `BOOM(o)` صوت كشف.
- أشكال جاهزة ترجع path: `CI(x,y,r)` دايرة، `EL(x,y,a,b)` بيضاوي، `MAN(x,y,h)` شخص، `KEY(x,y,s)` المفتاح (موتيف السيادة)، `CHAIR`, `BOOK`.
- ألوان: G, GD, N, R, Y, YD, SAND, GR.

## شروط التسليم (كلها لازم تعدّي)
```
cd /home/claude/out
BOARD=/home/claude/out/<file>.html NODE_PATH=$(npm root -g) node gaps.js 3.2     # الهدف: lines still >3.2s: 0
BOARD=... TAG=<B_> NODE_PATH=$(npm root -g) node tb.js    # أول سطر JSON: bad [] و ov [] ، وآخر سطر errs []؛ وبيصور f_<TAG><id>.png
BOARD=... NODE_PATH=$(npm root -g) node tk.js             # لازم ينتهي بـ errs []
BOARD=... TAG=<B_> NODE_PATH=$(npm root -g) node fr.js B1.1 B2.4 ...   # فريمات g_<TAG><id>.png عند 93% من السطر — بص عليها فعلًا
```
- كل عبارة منطوقة ليها رسمة أو كتابة لحظة نطقها (مش قبلها بأكتر من 0.3ث). الجملة اللي فيها 3 حاجات = 3 رسومات على كلماتها.
- الرسمة تعني نفس اللي بيتقال. مفيش حشو زخرفي. مفيش معلومة أو تسمية مش في الكلام المنطوق.
- كروت «احفظ دي»: نص الكتاب بلفظه + رابط الحفظ المرسوم بتاع مدرب الحفظ.
- آخر السبورة: الكاميرا تبعد وتبيّن الورقة كلها (خلّي المحتوى فوق آخر 12%).
