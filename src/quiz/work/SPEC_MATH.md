# Extra rules for MATH / STATISTICS / MECHANICS quizzes (on top of SPEC_GEN.md)
The OCR of math books is readable for prose, headings, definitions and rules, but formulas are mostly garbled.
- Use the dump to learn WHAT each lesson teaches (its headings, definitions, rules, the kinds of examples and exercises, the notation such as س، ص، ن، ر، ت، ع, ق، ك). Then write your own questions of exactly those kinds, at the book's level. Standard mathematics that the lesson teaches is allowed even when its formula is garbled in the OCR; do not go beyond the lesson's scope.
- Mix: about half conceptual/rule questions (definition, property, which formula/condition applies), half short numeric problems solvable in 1-3 steps without a calculator where possible.
- VERIFY EVERY numeric answer with plain Python (math, cmath, fractions, itertools; sympy is NOT available — for derivatives/integrals check numerically, e.g. finite differences or Simpson integration): write a small script that recomputes each problem and checks that exactly one option equals the result and the other three do not. Keep that script at /home/claude/khutwa/quiz/check_<name>.py and run it before you finish.
- Notation in questions: Arabic text with Latin math, plain ASCII: x^2, sqrt(3), 3/4, pi, (x+1)^5, z = 1 + i, |z|, arg(z), e^x, ln x, dy/dx, ∫ is written as "تكامل" in words or ∫ (allowed), angles in degrees with "°". Prefer the book's Arabic variable names when the book is Arabic (س، ص، ع، ن، ت) but keep expressions readable, e.g. (س + 2)^6. Use the same style consistently inside a lesson.
- Distractors should be the results of typical student mistakes (sign error, forgetting a factor, wrong formula).
